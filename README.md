# Zaravi Typography

Design exploration for the Zaravi Gold platform, integrating the Kalameh Persian typography system and rhythmic brand color palette.

## Overview

This repository documents the design exploration that introduced the Kalameh font family and brand quad color palette into the Zaravi Gold web platform.

## Features

- Kalameh web font integration across Regular, Medium, Bold, and ExtraBold weights.
- Early chromatic explorations for gold bullion and jewelry e-commerce.
- Next.js and Prisma project scaffold.
